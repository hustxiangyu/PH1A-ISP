# PH1A-ISP

**基于安路 ANLOGIC PH1A（anph1a90）的实时视频处理平台**

> 2024 年全国大学生嵌入式芯片与系统设计竞赛 —— FPGA 赛道（安路）**全国一等奖**作品

---

## 简介

PH1A-ISP 是一套运行在安路 PH1A FPGA 上的实时视频处理系统。平台以摄像头 / HDMI-IN / SD 卡为多路数据源，通过自研 DDR 多通道读写仲裁完成帧缓存，再经可裁剪的 ISP 流水线输出至 HDMI 显示器。整条链路支持 1920×1080 实时处理，并提供无极缩放、分屏对比、一键截屏、人脸检测与水印叠加等特性，可广泛应用于安防监控、工业检测与互动娱乐等场景。

## 系统框图

![系统总体框图](docs/system_block_diagram.svg)

数据通路概览：

1. **采集**：摄像头 RAW 数据经 CSI 解包、裁剪后转为 RGB888；HDMI-IN 解码为 24-bit RGB。
2. **缓存**：图像写入 DDR3，由自研 FDMA 仲裁模块统一调度多通道读写。
3. **处理**：ISP 流水线对像素流做实时处理，各模块可通过寄存器独立开关。
4. **显示**：经无极缩放与分屏合成后，由 HDMI TX 输出到显示器；SD 卡支持截屏存档与图片回显。

## 主要特性

### ISP 图像处理流水线

| 模块 | 说明 |
| --- | --- |
| 去马赛克 Demosaic | RGGB Bayer 插值，结合色差恒定约束抑制伪色 |
| 自动白平衡 AWB | 灰度世界假设，逐帧统计通道均值并施加增益 |
| 色彩校正 CCM | 基于 24 色卡 + 最小二乘求解 3×3 色彩校正矩阵 |
| Gamma / 对比度 | LUT 实现非线性亮度映射，支持 7 挡亮度与对比度调节 |
| 锐化 EE | 拉普拉斯算子增强高频细节 |
| 滤波 | 均值滤波 / 中值滤波，降噪并保留边缘 |
| 二值化 | YUV 色域全局阈值（帧均值法） |
| 腐蚀 / 膨胀 | 3×3 形态学运算，去噪与连通区域修补 |
| 边缘 / 轮廓 | Sobel 边缘检测；形态学梯度轮廓提取 |
| 人脸检测 | YCbCr 肤色阈值提取 + 行列扫描画框，强光/复杂背景下稳定工作 |
| 水印 | ROM 初始化图案，支持直接叠加与半透明叠加 |

### 无极缩放

基于最近邻插值的实时 Scaler：由输入 / 输出分辨率计算缩放系数，将输出像素坐标映射回原图取样，支持任意比例平滑缩放，兼顾图像质量与资源占用。

### DDR 多通道读写仲裁

针对传统 AXI4 仲裁消耗 LUT/BRAM 过多、通道数上升后时序难收敛的问题，自行设计了基于 FDMA 的多通道读写仲裁器：以阻塞式优先级调度各通道请求，资源可控、通道数可扩展，DDR 利用率可达 90%。

### 分屏显示

支持多路视频源拼接显示与处理前后同屏对比；各路先经无极缩放适配子窗口尺寸，再由 DDR 仲裁统一读出并合成。

### SD 卡截图与回显

- SPI 模式下完成 SD2.0 初始化、单块 / 多块读写；
- 按键触发将当前帧（RAW8）写入 SD 卡，写入期间暂停摄像头输入以保证一致性；
- 支持从 SD 卡读图回显；SDIO 4-bit 模式高速读已完成验证，速率约为 SPI 的 4 倍。

## 关键性能

- 视频规格：**1920×1080** 实时处理与输出
- DDR 利用率：约 **90%**
- 无极缩放：支持任意缩放倍率，边缘平滑无阶梯感
- 人脸检测：强光照、复杂背景下稳定框选
- SD 截屏：SPI 模式整帧写入约 4 s（SDIO 模式可显著缩短）

## 开发与部署

1. 安装安路 **TD（Tang Dynasty）** 开发环境。
2. 新建 PH1A（anph1a90）工程，将 `rtl/` 下各目录加入源文件列表，`constraints/` 下 `pin.adc`、`timing.sdc` 加入约束。
3. 如需重新生成 IP，使用 TD 的 IP Catalog 按 `rtl/ip_source/` 中现有配置创建同名 IP。
4. 综合 → 布局布线 → 生成比特流，下载到开发板。
5. 上电后通过按键切换 ISP 处理模式，HDMI 显示器实时查看效果。

> 顶层为 `rtl/hdl_source/design_top_wrapper.v`。
